# Ανατολή Παπαδοπούλου — Ιστοσελίδα

React + Vite.

- `npm install` — εγκατάσταση (μία φορά)
- `npm run dev` — τοπική προβολή στο http://localhost:5173
- `npm run build` — παραγωγή στατικών αρχείων στον φάκελο `dist/` (για ανέβασμα σε Netlify, Vercel, κ.λπ.)

## Επεξεργασία
- **Κείμενα / στοιχεία επικοινωνίας:** `src/content.js`
- **Χρώματα / γραμματοσειρές:** μεταβλητές στην αρχή του `src/styles.css`
- **Φωτογραφία:** βάλτε `public/portrait.jpg` και δείτε το σχόλιο στο `src/components/About.jsx`
